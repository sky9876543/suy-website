# SUY Studio website

Static English landing page for SUY Studio at suy.app.

## Preview

From this directory, run:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Open http://127.0.0.1:8765. No installation or build step is required.

## Publishable files

- index.html
- styles.css
- favicon.svg

The illustration is original inline SVG. All visual assets and fonts are local or system-provided. There is no analytics, form backend, third-party script or visitor data storage. The contact action opens the visitor's email application.

## Hosting

Designed for GitHub Pages, publishing from the main branch and repository root. The custom domain is suy.app. Configure the custom domain in GitHub Pages before updating website DNS. Preserve Google Workspace mail records when setting up the website.
